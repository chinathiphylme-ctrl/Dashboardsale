# Hylme Dashboard — แบบเข้ารหัส

`index.html` ที่อยู่บน GitHub คือหน้าใส่รหัส + แดชบอร์ดที่ถูกเข้ารหัสทั้งไฟล์ (AES-256-GCM, กุญแจจาก PBKDF2-SHA256 600,000 รอบ)
ถ้าไม่มีรหัสผ่าน จะอ่านข้อมูลลูกค้าในไฟล์ไม่ได้ แม้จะเปิดดูโค้ดก็ตาม

| ไฟล์ | ขึ้น git? | คืออะไร |
|---|---|---|
| `index.html` | ✅ | ไฟล์ที่เข้ารหัสแล้ว (สร้างจากคำสั่งด้านล่าง) |
| `tools/` | ✅ | หน้าใส่รหัส + สคริปต์เข้ารหัส |
| `private/` | ❌ (อยู่ใน .gitignore) | ไฟล์ต้นฉบับที่ยังไม่เข้ารหัส — **ห้ามอัปขึ้น git** |

## คำสั่ง (ต้องมี Node.js 18 ขึ้นไป)

```
node tools/lock.mjs              # เข้ารหัส private/dashboard.html -> index.html
node tools/lock.mjs --unlock     # ถอดรหัส index.html กลับเป็น private/dashboard.html
```

## อัปเดตข้อมูล
- ปุ่ม **ส่งข้อมูลขึ้น GitHub**: data.json จะถูกเข้ารหัสด้วยรหัสเดียวกับเว็บก่อนส่ง
- ปุ่ม **สร้างไฟล์เว็บ**: ได้ index.html ที่เข้ารหัสแล้ว อัปขึ้น GitHub ได้เลย
- ปุ่ม 🔒 มุมบนซ้าย: ล็อกและลบรหัสที่จำไว้ในเครื่องนั้น

## เปลี่ยนรหัสผ่าน
รัน `node tools/lock.mjs` แล้วใส่รหัสใหม่ จากนั้นอัป index.html ขึ้น GitHub แล้วกด "ส่งข้อมูลขึ้น GitHub" ใหม่อีกครั้ง (data.json เดิมใช้กับรหัสเก่า)
