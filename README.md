# Hylme Dashboard

ใครมีลิงก์ก็เปิดดูได้เลย ไม่ต้องใส่รหัส แต่**ชื่อ / เบอร์ / ที่อยู่ลูกค้าเป็นค่าปลอม**
- ค่าปลอมคงที่ต่อคน (ลูกค้าคนเดิม = ค่าปลอมเดิม) ยอดขาย ลูกค้าใหม่/เก่า ออเดอร์ยกเลิก ทุกตัวเลขจึงเท่าข้อมูลจริง
- ข้อมูลจริงทั้งหมดถูกเข้ารหัส (AES-256-GCM, กุญแจจาก PBKDF2-SHA256 600,000 รอบ) ฝังอยู่ในไฟล์เดียวกัน
- กด 🔒 มุมบนซ้าย แล้วใส่รหัส จะสลับเป็นข้อมูลจริง ถึงจะ **ดาวน์โหลด / export Excel / เข้าหลังบ้าน** ได้
- ค่าปลอมสร้างจาก HMAC ที่ใช้กุญแจจากรหัสผ่าน ไม่มีรหัสก็ย้อนกลับเป็นชื่อ/เบอร์จริงไม่ได้

| ไฟล์ | ขึ้น git? | คืออะไร |
|---|---|---|
| `index.html` | ✅ | หน้าเว็บ (ข้อมูลปิดชื่อ/เบอร์ + ข้อมูลจริงที่เข้ารหัส) |
| `tools/build.mjs` | ✅ | สคริปต์สร้าง index.html |
| `private/` | ❌ (อยู่ใน .gitignore) | ไฟล์ต้นฉบับที่มีข้อมูลจริง — **ห้ามอัปขึ้น git** |

## อัปเดตข้อมูลประจำวัน (ไม่ต้องใช้คำสั่ง)
1. เปิดหน้าเว็บ → กด 🔒 → ใส่รหัส
2. เข้าหลังบ้าน → อัปโหลดไฟล์ → กด **ส่งข้อมูลขึ้น GitHub** (data.json ถูกปิดชื่อ/เบอร์ + เข้ารหัสก่อนส่งเอง)
   หรือกด **สร้างไฟล์เว็บ** แล้วเอา index.html ที่ได้ไปอัปขึ้น GitHub

## คำสั่ง (ต้องมี Node.js 18 ขึ้นไป — รันใน PowerShell / Terminal ของตัวเอง)
```
node tools/build.mjs              # private/dashboard.html -> index.html
node tools/build.mjs --unlock     # index.html -> private/dashboard.html (ข้อมูลจริง)
```
ก่อนบันทึก build จะสแกนหาเบอร์/ชื่อจริงที่หลุดในไฟล์ผลลัพธ์ ถ้าเจอจะไม่เขียนไฟล์

## เปลี่ยนรหัสผ่าน
รัน `node tools/build.mjs` แล้วใส่รหัสใหม่ → อัป index.html → กด "ส่งข้อมูลขึ้น GitHub" ใหม่อีกครั้ง
(data.json เดิมใช้กับรหัสเก่า และเครื่องที่ "จำรหัส" ไว้ต้องใส่รหัสใหม่)
